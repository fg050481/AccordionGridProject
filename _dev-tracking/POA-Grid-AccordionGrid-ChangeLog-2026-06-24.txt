_newBuffer with empty strings from the readonly DOM inputs, since the upload
widget never writes back to those hidden fields.

  inside _finaliseInsert after _collectFormValues runs
- Store FileName and FileExtension into _newBuffer on upload success in _doUpload
- Add FileExtension to PoaFormDto so all three document fields reach the server
- Add FileExtension to the dto object built in onSave to match PoaFormDto contract
